# SwiftAgent Hooks

This directory contains hook scripts that enhance agent workflow behavior.

## Setup

### Step 1: Symlink hooks-scripts to your project directory

From the swift-engineering plugin directory:

```bash
ln -s $(pwd)/hooks-scripts /path/to/your/project/.hooks-scripts
```

Or using an absolute path:

```bash
ln -s /path/to/swift-agent/plugins/swift-engineering/hooks-scripts /path/to/project/.hooks-scripts
```

### Step 2: Configure your IDE hooks as needed

The hooks can be integrated with your IDE's hook system for automated workflow enforcement.

## Available Hooks

### UserPromptSubmit Hooks

These hooks run when a user submits a prompt:

- **skill-forced-eval-hook.sh** — Evaluates if required skills are being used
- **agent-forced-eval-hook.sh** — Evaluates if proper agent is being invoked

## Hook Behavior

When enabled, these hooks help maintain workflow discipline by:

1. Checking that agents invoke required skills before making decisions
2. Ensuring proper agent handoffs are followed
3. Validating that planning agents don't modify code

## Disabling Hooks

To disable hooks temporarily, remove the symlink or rename the hooks directory.
